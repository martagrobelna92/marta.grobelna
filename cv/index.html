Profile

Doctoral researcher at the Technical University of Munich developing algorithms for concurrent stochastic games and Markov decision processes with formal precision guarantees. I independently developed, proved correct, and implemented a novel value-iteration algorithm in the Java-based PRISM model checker, using linear and quadratic programming (AMPL, Gurobi) as core tools. At Fraunhofer IKS, I translated industry customers’ goals (BMW, Huawei) into mathematical models and working prototypes, and I maintain and migrate a production Python web platform (Automata Tutor). Next, I want to bring this experience to industry and tackle challenging real-world problems.

Experience

  • 2022 - present

    Munich, Germany

    Doctoral Researcher, Algorithm Development
    Technical University of Munich (TUM)
    • Design algorithms for stochastic games and Markov decision processes (MDPs), combining mathematical analysis, correctness proofs, software implementation, and computational evaluation.
    • Independently designed, proved correct, and implemented in Java the first value-iteration algorithm for concurrent stochastic games with guaranteed precision for maximum-reachability objectives, and integrated it into the PRISM probabilistic model checker (LICS 2025).
    • Formulated optimization problems arising from concurrent stochastic games in AMPL and solved them using Gurobi and other optimizers through the AMPL Java API.
    • Co-authored a paper on hot-starting and incremental value iteration for MDPs that reuses previous results when a model changes, with formal precision guarantees (under review).
    • Currently developing bounded strategy iteration and a new quadratic-programming formulation for concurrent stochastic games, and extending the methods to partially observable MDPs (POMDPs).
